LibreWallet

Lokalny tracker portfela na macOS. Twoje dane nie wychodzą z komputera.

Pobierz dla macOS GitHub Releases

Instalacja (ważne przy pierwszym uruchomieniu)

  1. Pobierz LibreWallet.zip i rozpakuj.
  2. Przenieś LibreWallet.app do folderu Aplikacje.
  3. Przy pierwszym otwarciu macOS może zablokować plik (brak notarizacji Apple).
  4. Kliknij apkę prawym przyciskiem → Otwórz → potwierdź Otwórz.

Aktualizacje

W aplikacji: menu LibreWallet → Sprawdź aktualizacje… albo Ustawienia → O programie. Aktualizację pobierasz ręcznie (ZIP) i podmieniasz apkę.

Kod źródłowy: github.com/wedishprocentahc/librewallet
