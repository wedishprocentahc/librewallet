LibreWallet

Natywna aplikacja macOS (SwiftUI) do śledzenia portfela. Dane zostają na Twoim Macu — bez chmury.

Pobierz native macOS Instrukcja instalacji

Co dostajesz

  1. Import XTB ZIP, CSV uniwersalny oraz IBKR CSV
  2. Dashboard z benchmarkami, zwrotami pozycji, rebalancingiem i obligacjami skarbowymi
  3. Cashflow, uproszczony raport podatkowy PL oraz alerty cen
  4. Backup JSON / eksport CSV — dane lokalne

Instalacja (Gatekeeper)

  1. Pobierz LibreWallet.pkg (preferowane) lub ZIP z Releases.
  2. Zainstaluj / przenieś LibreWallet.app do Aplikacje.
  3. Przy pierwszym otwarciu: prawy przycisk → Otwórz (apka nie jest jeszcze notaryzowana).

Szczegóły notarizacji dla maintainerów: docs/NOTARIZATION.md.

Aktualizacje

W aplikacji: menu LibreWallet → Sprawdź aktualizacje… albo Ustawienia. Preferowany instalator to .pkg.

Legacy

Starsze buildy Electron/pkg (1.x) pozostają w archiwum Releases wyłącznie do konserwacji. Nowy rozwój idzie wyłącznie w native macOS (0.5+).
